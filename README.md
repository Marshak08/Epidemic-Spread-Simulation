# Epidemic Spread Simulation

## Project Description
This project simulates the spread of an epidemic among a population of 1000 people using C++ and OpenMP.

## Technologies
- C++
- OpenMP
- Visual Studio

## How to Run
1. Open EpidemicSimulation.sln in Visual Studio.
2. Make sure OpenMP support is enabled.
3. Build the project.
4. Run the program using Ctrl + F5.

## Program Features
- Sequential simulation.
- Parallel simulation using OpenMP.
- Daily statistics of healthy, infected, and recovered people.
- Execution time comparison.
- Speedup and efficiency calculation.
